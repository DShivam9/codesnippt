# ⚡ SNIPCAST

### Turn your source code into **beautiful, shareable** images.

[![Live](https://img.shields.io/badge/🔴_LIVE-codesnippt.vercel.app-FF9F0A?style=for-the-badge)](https://codesnippt.vercel.app)

<br/>

**Snipcast** is a code snippet image generator with a bold, unapologetic **brutalist design**. Paste your code, pick a theme, and export a stunning screenshot — no sign-ups, no watermarks, no backend. Everything runs in your browser.

<br/>

[🚀 **Launch Studio**](https://codesnippt.vercel.app/studio) · [🌐 **Visit Website**](https://codesnippt.vercel.app) · [🐛 **Report Bug**](https://github.com/DShivam9/codesnippt/issues)

</div>

## ⚙️ How It Works

```
1. Paste your code
2. Pick a theme (28+ options from GitHub Dark to Synthwave '84)
3. Customize the background, padding, and font size
4. Export as a high-quality PNG — done.
```

Your code **never leaves your browser**. Zero backend, zero tracking.

---

## ✨ What You Get

- 🎨 **28+ Syntax Themes** — VS Code-grade highlighting powered by Shiki
- 🌈 **Vibrant Backgrounds** — Curated gradients and bold solid colors
- 💻 **Multi-Language** — JS, TS, Python, Rust, Go, HTML, CSS, SQL, Bash, JSON & more
- 📐 **Adjustable Padding & Font Size** — From compact tweets to presentation slides
- 🪟 **Window Chrome** — Toggle macOS-style traffic light dots
- 📤 **One-Click Export** — Clean PNG, ready to share anywhere
- ⚡ **Fully Client-Side** — Nothing is sent to a server, ever

---

## 🎨 The Design

Snipcast doesn't look like every other dev tool. It's built with **brutalism** at its core:

> Stark black & white. Thick 4px borders. Hard offset shadows. Punches of orange. Oversized typography that demands attention. GSAP-powered cinematic animations.

The tool itself is an experience — because sharing your code should feel creative, deliberate, and undeniably stylish.
